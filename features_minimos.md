# Features Mínimas
1. Interface de usuário simples para adição de palavras e aprendizado.
2. Função de repetição da pronúncia.
3. Função de tradução para diferentes idiomas.
4. Sistema de pontuação para motivação do usuário.
5. Recursos de feedback personalizados.
6. Integração com um banco de dados de aprendizado.
7. Suporte para múltiplos dispositivos.
8. Funções avançadas de personalização e ajustes.
9. Exercícios personalizados com diferentes tipos de palavras e frases.
10. Monitoramento e feedback do progresso do usuário.
