# Frontend (Expo) — Scaffold

Passos para rodar localmente:

1. Instale Node.js e expo-cli globalmente (ou use npx):

```
npm install -g expo-cli
```

2. Instale dependências e inicie:

```
cd frontend
npm install
npm run start
```

3. No app, o frontend assume que o backend está em `http://localhost:8000`.

Observações:
- Em dispositivos físicos, substitua `localhost` pelo IP da máquina de desenvolvimento.
- Este scaffold é mínimo — adicione telas, estilos e autenticação conforme necessário.
